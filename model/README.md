# Model Artifacts (`model/`)

This directory is the destination for the serialized machine learning artifacts generated by the `create_model.py` training script.

## Artifacts Generated
*   **`model.pkl`**: The trained scikit-learn Pipeline.
*   **`model_features.json`**: The ordered list of features expected by the model.

## Training Pipeline Improvements (KNN Imputation)

In the real world, data is messy. To handle missing values robustly (e.g., if a user doesn't know their lot size or number of bathrooms when making an API request), we upgraded the training pipeline to include a **K-Nearest Neighbors (KNN) Imputer**.

### How it Works:
1.  **Integration**: The `KNNImputer(n_neighbors=5, weights="distance")` is now injected as the very first step in our `sklearn.pipeline.Pipeline`.
2.  **Mechanism**: When a prediction request arrives with `null` values, the imputer looks at the 5 most similar homes in the training space (based on the provided, non-null features) and estimates the missing values using a distance-weighted average.
3.  **Benefit**: The API no longer throws 500 Internal Server Errors or requires strict input completeness. It gracefully handles missing data, dramatically improving the user experience and the system's overall resilience in a production environment.
